# 自动高亮

调用思源中已配置的 AI 挑选当前文档的重点并上色：

- **核心重点** — 红色 `#e53935`
- **重要信息** — 蓝色 `#1e88e5`
- **行动项** — 橙色 `#fb8c00`
- **结论** — 绿色 `#43a047`

点击顶栏按钮可选择：AI 高亮整篇文档、AI 高亮选中内容、清除本文档高亮。

高亮通过 `/api/block/updateBlock` 写成行内颜色标记，保留块 ID 和其他属性；已有行内颜色的文本不会被重复处理。

使用 Vite 8 + TypeScript + Svelte 5 重建。

## 要求

- 思源桌面端 3.7.0 及以上。
- 已在「设置 → AI」中配置可用的模型。

## 开发

```bash
pnpm install
pnpm dev
pnpm check
pnpm build
```
